# Project Archive

## Purpose

This file stores projects, ideas, experiments, and goals that are not currently active.

The purpose is to preserve ideas without allowing them to distract from current priorities.

Archived does not mean abandoned.

It means:

"Not the current focus, but worth remembering."

# Future Ideas

Ideas should be recorded here before becoming active projects.

Before activating an archived project, evaluate:

1. Does this support current goals?
2. Is this the highest-value use of time?
3. Do I have the resources needed?
4. What current priority would be delayed?

# Completed Projects

Completed projects can also be moved here with:

* Completion date.
* Results.
* Lessons learned.
* Skills gained.
