## OmniRoute

Status:
Active — running on local ThinkPad

Purpose:

Local OpenAI-compatible AI routing gateway. Handles model selection, fallback, and provider routing so client apps don't need to.

Integration points:
- OpenCode: configured as default provider (`omniroute/auto/best-chat`)
- My Agent: primary backend
- `tools/model_router.py`: Python client module for programmatic access
