# Build

1. Identify the requested outcome, constraints, and done condition.
2. Inspect only relevant source and instructions. Plan complex changes before editing.
3. Implement complete behavior within the agreed scope. Add error handling, logging, and retries where their failure consequences justify them.
4. Verify changed behavior with appropriate existing checks or targeted regression tests.
5. Record material decisions, evidence, and remaining limitations. Commit explicit paths when authorized.

A bounded experiment is valid. Do not add unrelated features or require production infrastructure for every personal tool.
