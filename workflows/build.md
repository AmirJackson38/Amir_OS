# Workflow: Build

## When to Use

- Implementing a new feature
- Creating a new component
- Adding functionality to existing code

## Steps

1. **Load context** — Read relevant skill files, understand the domain.
2. **Review design** — If no plan exists, run the Plan workflow first.
3. **Implement** — Write complete, production-ready code with error handling, logging, edge cases.
4. **Verify** — Check syntax, run linters, validate against existing tests.
5. **Document** — Update memory files if architectural changes were made.
6. **Commit** — Git commit with descriptive message explaining what and why.
