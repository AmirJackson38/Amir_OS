# Workflow: Research

## When to Use

- Exploring an unfamiliar codebase
- Investigating a technology or library
- Gathering requirements
- Understanding existing architecture

## Steps

1. **Define scope** — What specific questions need answers?
2. **Identify sources** — Code, documentation, configuration files.
3. **Read strategically** — Start with READMEs, architecture docs, then drill into code.
4. **Synthesize** — Summarize findings, highlight key patterns and decisions.
5. **Present** — Share findings with recommendations.
