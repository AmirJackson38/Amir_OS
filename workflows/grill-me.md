# Workflow: Grill Me

## When to Use

- Requirements are ambiguous or incomplete
- Multiple valid approaches exist with different trade-offs
- Key decisions need to be made before proceeding
- The user has not specified important constraints

## Steps

1. **Identify ambiguities** — What requirements are underspecified?
2. **Formulate questions** — Ask specific, targeted engineering questions.
3. **Present trade-offs** — For each decision point, explain the options and consequences.
4. **Listen** — Let Amir answer before proceeding.
5. **Confirm** — Verify understanding of the answers before designing.
