# Agent rules

The current collaboration contract is `identity/COLLABORATION.md`. Start at `START_HERE.md`; follow `AGENTS.md` for repository work.

Use task-specific context and preserve original evidence. A generated packet is a view, not truth. Old character budgets and automatic resume/promotion rules are superseded by `MEMORY_PROTOCOL.md`.

When asked to learn, connect an explanation to an attempt and evidence. When asked to build, complete the agreed scope with proportionate verification. Do not expand every task into a complete product.

Workflow names such as /plan, /learn, and /grill-me are conventions for clients that support them, not installed capabilities or automatic permission to act.
