# Startup

Read `START_HERE.md`, then `identity/COLLABORATION.md`. Choose the route for the user's current task.

For repository work follow `AGENTS.md`. For TARS read `HEAD.md` and verify Git; check production separately when needed. For learning use Obsidian Home and Learning Queue.

Do not load old BOOTSTRAP_v2 or the entire vault by default. No readiness ceremony or repeated permission question is needed when the user already gave a clear task.
